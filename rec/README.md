# 숨바꼭집 녹화판 (/rec/)

Pages 저장소 `hide-and-home-play`의 `rec/` 폴더로 그대로 복사하면 돼요. 게임 파일은 복사하지 않아요.
- 이 폴더는 파일 3개(index.html, game.html, rec-inner.js)예요.
- game.html이 `<base href="../">`로 위의 게임을 그대로 불러요. 그래서 배포된 버전(지금 1.0.252)을 늘 따라가요. 저장(진행)도 본게임과 같아요.

## 쓰는 법
1. `https://sanghyukyoon-oss.github.io/hide-and-home-play/rec/?stage=28`처럼 열어요. `?stage=N`이 없으면 홈에서 시작해요. 오른쪽 위 '판 바로 가기'로도 바꿀 수 있어요.
2. 게임을 하다가 오른쪽 위 ● 녹화 → ■ 정지를 누르면 파일이 바로 저장돼요.
   - 크롬·사파리는 mp4로 저장돼요. 둘 다 mp4를 못 쓰는 브라우저면 webm이에요.
   - 1080×1920, 소리 포함이에요.
   - 버튼과 빨간 테두리는 게임 창 밖에 있어서 찍히지 않아요.
3. 'UI 빼고'(기본)는 게임 그림만 정확히 1080×1920으로 찍어요. 'UI 넣고'는 크롬 탭 화면 녹화라서 공유 창 허락이 필요하고, 해상도는 화면에 보이는 크기를 따라가요.

## 녹화판 전용 (10/26 추가)
- 저장 분리: 녹화판 안의 저장 키에는 모두 `rec:`가 붙어요. 본게임 진행에는 쓰지 않아요.
- 판: 1~70판(보스·놀이 포함)이 다 열려 있고, 튜토리얼 표시는 꺼져 있어요.
- 오른쪽 아래 구석(15%)을 1초 안에 5번 누르면 게임 UI·말풍선·녹화 버튼이 다 사라져요. 다시 5번 누르면 돌아와요.
  - 숨김 상태에서도 말풍선은 투명하게만 숨겨서 터치는 받아요.
- 오른쪽 위 구석을 1초 안에 3번 누르면 다음 판, 왼쪽 위 구석을 3번 누르면 이전 판으로 가요. 녹화는 끊기지 않아요.
- 구석에서 게임 화면(3D)을 누른 것은 이동·찾기로 넘기지 않아요. 구석의 HUD 버튼은 첫 번째 누름만 통과시켜요.

## 확인한 것 (10/26, 맥 크롬 헤드리스, 28판 10초)
- 녹화 파일: mp4(H.264 High + AAC), 1080×1920, 9.98초, 약 49fps(헤드리스 프레임 상한), 영상 약 29Mbps
- 소리: 들어 있어요(평균 −35dB, 최대 −21dB, 게임 음악·효과음)
- 화질 단계는 2(dpr 2, 슈퍼샘플 없음)로 고정했어요. 느려져도 해상도를 내리지 않아요.
- 'UI 넣고' 모드는 화면 공유 허락 창이 떠서 헤드리스로는 시험하지 못했어요. 실제 크롬에서 한 번 확인이 필요해요.
- 구석 연타(헤드리스): 3번 → 28→29판, 3번 → 29→28판, 5번 → UI·버튼 숨김, 다시 5번 → 돌아옴. 저장 키는 rec: 3개뿐이에요(본게임 키 0)
